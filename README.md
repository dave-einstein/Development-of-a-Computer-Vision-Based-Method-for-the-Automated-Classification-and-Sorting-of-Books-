# Development-of-a-Computer-Vision-Based-Method-for-the-Automated-Classification-and-Sorting-of-Books-
The aim of this research is to develop an automated library book classification and sorting system using open AI’s CLIP computer vision, Optical Character Recognition (OCR), and a mechanical conveyor mechanism
This research proposes a system capable of recognizing book categories from their cover images using CLIP computer vision model and automatically sorting them into designated compartments, reducing manual intervention and improving efficiency.
